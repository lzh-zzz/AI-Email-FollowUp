# Triage Labels

本项目保留技能默认的五种标签角色及对应名称。

| 技能中的角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格明确，可由 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不处理 |

技能提及标签角色时使用对应的本项目标签。此文件定义标签词汇，不代表远程仓库已创建这些标签。
