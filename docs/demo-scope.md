# Demo 当前交付范围

更新：2026-10-01。本文汇总已实现的交付范围；详细行为以根目录 [SPEC.md](../SPEC.md) 为准，实际验证与未完成项见 [verification.md](verification.md)。

## 交付方式

用户已选择本地交付：从 GitHub 下载或克隆代码，在接收方电脑配置并启动，访问 http://127.0.0.1:8000。环境、凭据和网络准备完成后的启动目标为五分钟内；无需部署线上服务。每位演示者使用自己的百炼账号、QQ SMTP 授权码和本人或公司提供的测试邮箱，业务数据保存在该电脑。

## 已实现的业务范围

- 使用虚构产品 PackPilot 演示定制环保包装服务；卖点仅限小批量定制、可回收材料、样品打样。
- 客户单个录入与 CSV 导入包含姓名、公司、职位、官网、邮箱、行业、国家／地区，支持字段校验和邮箱去重。
- 公司背景可手动填写，也可读取公开官网首页及最多一个同站 About 页面，由真实 AI 提取背景、来源和原文依据；没有可用背景时不能启动首封。读取本身不发信，创建首封任务后背景冻结。
- 真实百炼生成客户画像、切入点、依据及英文首封主题和正文，体现行业、公司背景或职位差异，区分事实与推测。
- QQ SMTP 真实发送。首封被接受后开始计时，默认 60 秒未录入回复时由 AI 生成并发送唯一一封跟进，之后不再安排更多自动跟进。
- 客户回复在页面手动模拟，明确记录来源，不读取实际邮箱回复。录入回复先取消未发送任务，再由真实 AI 判断高／中／低／拒绝意向，生成建议与可编辑英文草稿。
- 草稿可保存、编辑、上传或移除附件，再由用户点击发送；每条客户回复最多一封人工确认邮件。可继续多轮交流，人工回复成功后不安排新的未回复自动跟进。
- 明确拒绝、退订或人工停止后停止联系；合作达成可手动标记完成，保留历史。终态禁止后续发信，已完成会话也禁止录入模拟回复。
- 支持会话删除与清理关联本地记录，需确认；活动任务期间禁止删除，已发邮件不能撤回。
- SQLite 保存客户、会话、邮件任务、AI 结果、附件和官网读取；重启后恢复到期检查，防重复提交，并将不确定的 SMTP 结果暂停为待核实。

## 已采用的技术方案

Python 3.12+、FastAPI、静态 HTML/CSS/JavaScript、LangGraph、SQLite、APScheduler；单进程运行，调度器每两秒检查到期任务。百炼使用 qwen3.7-flash，默认关闭深度思考；QQ SMTP 默认 smtp.qq.com:465，使用 SSL/TLS 和邮箱授权码。模型及跟进间隔可配置。

架构图见 [README](../README.md#技术栈与架构)，操作讲稿见 [demo-guide.md](demo-guide.md)。

## 验收与证据边界

- 首封与自动跟进实际到达测试邮箱：用户已于本次交付收尾中确认收到；按用户要求不记录收件日期和时间。SMTP 提交日志与收信确认分开保存，不编造截图或精确投递时间。
- API 失败、模型输出异常、邮件发送失败、重复执行和重启恢复均有实现及自动化测试；外部模型与 SMTP 替身测试不代替真实能力验收。
- SPEC.md 的“推荐测试边界”仍为待确认草案，不因测试已运行而自动改为正式确认。
- 附件邮件实际到达及附件可打开的独立人工确认尚未收到，保持待确认；这项不等同于必需的首封／自动跟进收信验收。

## 范围限制

仅本地单进程，无多用户登录与生产公网部署；关闭或休眠时不执行任务。官网仅支持有限公开 HTML，不执行 JavaScript、不登录、不处理验证码。没有 IMAP、收件 webhook、自动读取客户回复、打开追踪、自动退信处理或多轮自动营销功能。SMTP 接受不保证外部投递恰好一次，结果不确定时禁止盲目重发。
