# 5–10 分钟演示讲稿

准备：启动应用，确认“配置就绪”。准备本人或公司提供的测试收件箱，产品和公司用虚构样例。不要显示 `.env`。

| 时间 | 操作 | 展示结果 |
| --- | --- | --- |
| 0:00–1:00 | 录入 Northline Beauty 样例，填写测试收件地址 | 八项客户字段、公司背景、未发送状态 |
| 1:00–2:00 | 点击“AI 分析并发送首封” | 采购画像、小批量试销切入点、英文主题与正文 |
| 2:00–3:00 | 查收首封，保持页面，不录入回复 | SMTP 接受记录、倒计时、实际邮件 |
| 3:00–4:00 | 等待倒计时结束 | AI 跟进邮件、第二条记录、本轮跟进结束 |
| 4:00–5:00 | 点击“感兴趣”，保存回复 | 模拟来源、高意向、建议与未发送草稿 |
| 5:00–6:00 | 试“需要资料”“暂不需要” | 中/低意向差异，发送数量仍为两封 |
| 6:00–7:00 | 录入“明确拒绝”或“退订” | 拒绝意向、停止原因、草稿为空、禁止重新开发 |
| 7:00–8:00 | 刷新、展开时间线、讲解架构 | 记录持久保存，数据库和调度器职责 |

附加分支：用第二个获准地址录入另一个客户，发送首封后在一分钟内录入任何回复。待发送跟进立即变为已取消，即使分析失败也不恢复。或点击“停止自动跟进”观察人工停止。

只有一个地址时，停止应用后改名备份 `data` 目录，再启动新一轮演示。请保留备份；同一数据库的邮箱不能重复创建或重新开发。

讲解重点：行业、职位和背景让内容有实质差异；页面区分 AI 生成与发送、SMTP 接受与实际收信、模拟回复与自动读取。拒绝后再录入积极回复也不会恢复自动开发。
